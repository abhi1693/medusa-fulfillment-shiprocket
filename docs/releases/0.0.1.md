First public release of `@abhi1693/medusa-fulfillment-shiprocket@0.0.1` for Medusa 2.22.4.

- Quote delivery from eligible stock locations, preserve customer rates in signed package plans and support single or split shipments.
- Verify and store account credentials and shipping settings in the owning module, with separate test and live modes. New installations start with fulfillment disabled.
- Link existing pickup addresses, handle partial allocations and retain carrier order and shipment IDs across uncertain AWB and pickup outcomes.
- Ship server and Admin builds, TypeScript declarations, reusable Admin components and the public consumer adapter contract.

Apply the plugin’s native migrations and configure its connection, webhook token and pickup mappings in the consuming application. The offline suite covers simulated carrier responses. Live account rates, shipment booking, AWB assignment and pickup require separate acceptance with the merchant account.
